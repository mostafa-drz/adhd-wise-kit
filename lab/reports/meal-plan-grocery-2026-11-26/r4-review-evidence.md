## SKILL.md changes, most important first

1. **Cut the plan reply's load** (Maya, criterion 3, two rounds).
   - The weekly plan, step 5: "Show the buy list as one line with the count: `To buy (15):
     spinach, sweet potatoes, red onions, ...`. Group it by aisle only if they ask or nothing
     is connected." Update the template to match.
   - Safety: replace "say so if a meal could contain a common allergen" with "Flag allergens
     only for allergies they named, including hidden sources (peanut in curry paste, sesame in
     dressings). With no allergy named, no allergen line."
   - Rules for every reply: "The step or question comes before any context."
2. **Memory answers that fit where they are** (Lee r3, Sam r4). In Where the list lives,
   option 3:
   - "Will you remember?" with memory on: `I've asked memory to keep the item names. It can
     miss things.` Then only the option that fits (iPhone: Reminders; computer or Android:
     Todoist). On the low path, stop after the first two sentences.
   - With memory off: `Not in a new chat. It's kept in this chat; copy it if you like.`
   - "On a list read from memory, the From-memory line comes first, then nothing else above
     the list." (resolves the clash with At the store).
3. **Two honest scripted lines for shared lists** (Maya). In The running list, step 1, Shared
   lists:
   - "If their item has no quantity and you need a set amount, don't assume it covers you: say
     it in one line (`Jonah's eggs are on; you need 6 for Mon.`)."
   - "Asked whether the other person gets notified: `I can't see their notification settings,
     so I can't promise either way.` Never guess how the app behaves."
4. **Low path: the placeholder and "no more numbers"** (Sam).
   - Step 2 no-cook list: "Once they name something they like, it replaces the `Something you
     like` line." Optionally write it as a prompt under the list instead of an item.
   - "If they ask for no more numbers, give none, and that also ends route retries (no phone or
     online version after it). Acknowledge in three words or fewer."
   - Swap the stock normaliser: the first-reply feeling line uses their words, not "happens to
     loads of people".
5. **Undo on the Allow line** (Ruth). On the yes: `...tap Allow Full Access; it's how I add to
   your list. You can change it in Settings.` (a few words; the low-trust user asked herself
   exactly this).
6. **Siri tip timing** (Maya). "Mention once, the first time items go on a Reminders list in
   this chat" (not only when the list is made), so people with an existing list hear it too.
7. **Carry-overs from round 3, low priority:** one optional delivery line when they mention
   ordering (`Paste it into a delivery app if that's easier.`, never an order or an offer to
   order); one canonical reply to a "k" after the trip ended (`On the list for next time:
   cheddar, eggs.`); the "5 dinners" header can say "4 to cook" when one night is leftovers.
